# FLANKER — Су-27 Flight Laboratory

Трёхмерный симулятор самолёта на **C# / .NET 10 / Raylib**. Сдержанная серая палитра,
процедурная модель Су-27, аэродром и горная долина. Основной акцент — динамика полёта,
а не боевые задания или эффекты. Для запуска не нужны Unity, Godot или редактор сцен.

## Запуск в VS Code

1. Установите **[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)**,
   VS Code и расширение **C# Dev Kit**. Нужен именно SDK, не только Runtime.
2. Распакуйте ZIP или клонируйте репозиторий, откройте папку с `Plane.csproj`.
3. В терминале этой папки выполните:

```sh
dotnet run
```

Первый запуск сам восстановит пакет `Raylib-cs` из NuGet. Все исходники приложения —
файлы `.cs`; точка входа — `Program.cs`, проект — `Plane.csproj`.
`Ctrl+Shift+B` собирает проект, `F5` запускает отладку. `Esc` закрывает окно.

Поддерживаемые пакетом платформы: Windows x64, Linux x64, macOS x64/Apple Silicon.
В этой разработке проверены Linux x64, .NET SDK 10.0.402 и Mesa OpenGL.
Windows и macOS требуют отдельной проверки на этих ОС.
Нужен графический рабочий стол и OpenGL 3.3; это настольная программа, не веб-приложение.

Linux (Debian/Ubuntu), если отсутствуют системные библиотеки:

```sh
sudo apt-get update
sudo apt-get install libgl1 libx11-6 libxcursor1 libxrandr2 libxinerama1 libxi6 libasound2t64
```

На старых версиях Ubuntu пакет ALSA называется `libasound2`.

## Прозрачность окна

По умолчанию **всё окно прозрачно на 20%**, то есть его непрозрачность — 80%.
`F8` уменьшает непрозрачность на 10 процентных пунктов, `F9` увеличивает;
диапазон — 20–100%. Пример запуска с непрозрачностью 20% (прозрачностью 80%):

```sh
dotnet run -- --opacity 0.2
```

Для полностью непрозрачного окна: `dotnet run -- --opacity 1.0`.
Используется прозрачность нативного окна, включая сцену и приборы. Нужна поддержка
композитора рабочего стола. В Linux с X11 проверена установка свойства
`_NET_WM_WINDOW_OPACITY = 0.8`; в облачном Xvfb без композитора визуальное смешивание
с фоном не проверялось. Поддержка на Windows, macOS и Wayland требует проверки
в соответствующем рабочем столе. Снимки самого framebuffer не включают фон рабочего стола.

## Первый полёт

Приложение открывается на взлётной полосе: **самолёт неподвижен, шасси выпущены,
газ на нуле, форсаж выключен, стояночный тормоз включён**. Двигатели работают на
малом газе: 55% оборотов в этой модели. Разбег и взлёт выполняет пилот самостоятельно.
Газ, триммер и траекторию меняет пилот: автопилота и автоматического
поддержания высоты/скорости нет.

| Клавиши | Действие |
| --- | --- |
| ↑ / ↓ | Отдать ручку / взять на себя; опустить / поднять нос |
| ← / → | Крен влево / вправо |
| A / D | Руль направления; на земле также носовое колесо |
| W / S | Увеличить / уменьшить газ |
| Left Shift | Включить / выключить форсаж; действует при полном газе |
| Q / E | Триммер: нос вниз / нос вверх |
| G | Выпуск / уборка шасси, занимает 3,5 секунды |
| B | Воздушный тормоз |
| Space | Держать колёсные тормоза |
| K | Включить / отпустить стояночный тормоз |
| F1 / F2 | Выключить / повторно запустить левый / правый двигатель |
| F8 / F9 | Уменьшить / увеличить непрозрачность окна |
| V | Внешняя камера → кабина → свободный облет |
| ПКМ + мышь | Вращение камеры в режиме ORBIT |
| Колесо мыши | Приближение / отдаление внешней камеры |
| N | Ветер с порывами, по умолчанию штиль |
| Tab | Силы на каждой поверхности, скольжение, отрыв потока, тяга и повреждение |
| P / H | Пауза / памятка управления |
| R | Новый старт на полосе с нулевым газом |
| T | Новый старт на полосе с нулевым газом |

Геймпад: левый стик — крен/тангаж, правый X — руль направления, мёртвая зона 6%.
Клавиатура остаётся доступной при подключённом геймпаде. Газ и переключатели — клавиатурой.

**Взлёт:** `T`, отпустите стояночный тормоз `K`, держите `W` до 100%,
включите форсаж `Left Shift`. Начинайте плавную ротацию около **300 км/ч IAS**:
короткими нажатиями `↓` поднимите нос примерно на 8–10°.
После отрыва уберите шасси. Клавиатура задаёт полный ход ручки, поэтому не
удерживайте её постоянно: добейтесь нужного тангажа, отпустите и подстройте триммер.
Числа здесь — ориентиры для этого прототипа, не руководство к настоящему самолёту.

**Посадка:** ориентир 280–310 км/ч IAS, шасси выпущены, небольшая вертикальная
скорость; после касания уменьшите газ и держите `Space`. Грубое касание
вертикальной скоростью более 8 м/с, удар крылом или фюзеляжем заканчивают полёт.

На приборах: IAS — эквивалентная приборная скорость из динамического давления
(без поправки на сжимаемость), ALT — метры над уровнем моря, RADALT — высота над
рельефом, AOA — угол атаки, LOAD — нормальная перегрузка от всех негравитационных
сил (включая реакцию шасси на земле),
V/S — вертикальная скорость. Положение точки CONTROL INPUT показывает реальное
сглаженное отклонение исполнительных поверхностей.

## Физическая модель

- **26 аэродинамических участков:** 16 полос крыла, 6 участков стабилизаторов,
  4 участка килей. У каждого — положение, площадь, хорда, собственный угол потока,
  подъёмная сила, сопротивление, циркуляция и степень отрыва.
- Местная скорость содержит `V + ω×r` и пространственную разность ветра. Вращение
  меняет обтекание крыльев по-разному: появляются физическое демпфирование крена,
  несимметричный срыв и взаимное влияние скольжения, крена и рыскания.
- Элероны, стабилизаторы и рули меняют углы обтекания поверхностей. Моменты
  получаются из `r×F` и профильного момента крыла. Различие сопротивления левого
  и правого крыла создаёт обратное рыскание при работе элеронами.
- Хвост получает оценочный скос потока крыла. Есть аппроксимация вихревой
  подъёмной силы стреловидного крыла и смещения центра давления на трансзвуке.
- **Неустановившееся обтекание:** циркуляция запаздывает, отрыв и повторное
  присоединение потока имеют разные постоянные времени. После уменьшения угла
  атаки крыло восстанавливает подъёмную силу постепенно. Критический угол
  отличается вдоль размаха, приблизительно 20–24° при типичных числах Рейнольдса.
- Числа Маха и Рейнольдса влияют на коэффициенты. Вязкость — формула Сазерленда;
  профильное сопротивление — приближение для ламинарного/турбулентного трения.
  Таблицы задают трансзвуковое волновое сопротивление и поправку подъёмной силы.
  Индуктивное сопротивление уменьшается вблизи земли (**ground effect**).
- **240 Гц, метод средней точки:** силы вычисляются в текущем и прогнозируемом
  состоянии. Вращение решает `I·ω̇ = M − ω×(I·ω)` с полным тензором инерции;
  ориентация — нормализованный кватернион. Результат проверяется при 480 Гц.
- Три оценочных топливных бака меняют **массу, центровку и тензор инерции**
  по теореме Штейнера. Все величины в СИ. У атмосферы ISA есть тропопауза 11 км.
- **Два независимых двигателя:** обороты и форсаж запаздывают, тяга зависит от
  высоты/Маха/оборотов и потерь на входе при больших углах атаки и скольжения.
  Тяга приложена к реальным разнесённым точкам; отказ двигателя вызывает рыскание.
  Топливо расходуется отдельно, пустые баки прекращают тягу.
- **Три амортизированные стойки**, ограничение хода, отдельные вращающиеся колёса,
  инерция колёс, продольное проскальзывание, боковой увод, круг сцепления,
  сопротивление качению и тормозной момент. Уравнение колеса/шины решается неявно,
  чтобы избежать численной неустойчивости при малой скорости. Угол руления
  носового колеса уменьшается с ростом скорости.
- Нос, хвост, законцовки и мотогондолы имеют отдельные точки столкновения с
  рельефом. Вертикальный удар более 8 м/с или чрезмерное сжатие разрушает шасси.
  Накопительная модель перегрузки учитывает превышение +9/−3 g и M 2,35.
  Повреждения условные: после достижения 100% полёт заканчивается.

Управление **прямое**, с ограничением скорости приводов и оценочной потерей их
эффективности при большом напоре. Клавиатура плавно отклоняет ручку до крайнего
положения. Реальной СДУ Су-27 и ограничителей перегрузки/угла атаки здесь нет:
полная ручка на большой скорости может повредить самолёт. Аналоговый стик удобнее.
Численный решатель балансировки используется только для начальных воздушных
сценариев теста отрисовки и физических тестов; в обычной игре старт всегда на земле.

Открытые размерные ориентиры: площадь крыла 62 м², размах 14,7 м,
пустая масса 16 300 кг, начальное топливо 5000 кг,
суммарная статическая тяга 149 кН без форсажа / 245,2 кН на форсаже.
Коэффициенты, геометрия и инерции находятся в `Flight/AircraftParameters.cs`,
`AerodynamicTables.cs`, `Aerodynamics.cs`, `MassProperties.cs`, `JetEngine.cs`.

**Границы достоверности:** это работающий исследовательский прототип, а не
сертифицированная или откалиброванная модель настоящего Су-27. Аэродинамические
коэффициенты, инерции, распределение топлива и характеристики двигателя оценочные.
Вихревая подъёмная сила, скос потока, гистерезис срыва и ground effect используют
инженерные аппроксимации. Не проверены реальные штопорные режимы и лётный конверт;
не моделируются реальная СДУ Су-27, упругость конструкции, физическое разрушение,
внутренняя газодинамика двигателя, приборные ошибки и сжимаемость в IAS.
Для калибровки нужны измеренные таблицы `CL/CD/Cm(α,β,M,δ)` и сравнение
с лётными испытаниями. Увеличение числа расчётов само по себе не подтверждает
совпадение с реальным самолётом.

Теоретические ориентиры:
[NASA: lift equation](https://www.grc.nasa.gov/www/k-12/airplane/lifteq.html),
[NASA: drag equation](https://www.grc.nasa.gov/www/k-12/airplane/drageq.html),
[JSBSim reference manual](https://jsbsim-team.github.io/jsbsim-reference-manual/).
JSBSim не является зависимостью проекта.

## Проверки

```sh
dotnet restore --locked-mode
dotnet build -c Release --no-restore
dotnet run -c Release --no-build -- --self-test
```

**29 физических тестов** обходятся без окна и GPU. Они проверяют атмосферу ISA,
масштабирование по динамическому давлению при фиксированных Mach/Re, работу сил,
стационарный и несимметричный срыв, память отрыва/присоединения потока, момент
от сил на хвосте, естественное демпфирование и обратное рыскание, скос потока,
ground effect, изменение центровки/инерции, отказ двигателя и потери в воздухозаборнике,
стояночный тормоз, разгон и взлёт тестовым пилотом, торможение и раскрутку колёс,
удар о землю, расход топлива, планирование, разворот при крене, кватернион,
60 секунд триммированного полёта и сходимость при 240/480 Гц.
Процесс возвращает ненулевой код, если хотя бы одна проверка не прошла.

Проверка графики в рабочем столе:

```sh
dotnet run -c Release --no-build -- --smoke-test
```

Она отрисовывает 420 кадров: начальная стоянка, полёт снаружи, вид из кабины; проверяет
состояние физики, неподвижность, нулевой газ и выпущенные шасси при старте,
контакт на стоянке и разнообразие пикселей, сохраняет три PNG
в `artifacts/` и завершается. Для Linux без монитора:

```sh
sudo apt-get install xvfb
xvfb-run -a dotnet run -c Release --no-build -- --smoke-test
```

Сам по себе тест отрисовки не доказывает лётную достоверность модели.

## Структура

```text
Plane.csproj                  .NET 10, закреплённый пакет Raylib-cs
Program.cs                    Точка входа, команды проверок
SimulatorApp.cs               Окно, ввод, цикл фиксированного шага
Flight/                       Атмосфера, силы, моменты, двигатели, шасси
Rendering/                    Процедурный Су-27, мир, камеры, приборы
Simulation/                   Рельеф и исполняемые физические тесты
.vscode/                      Сборка, отладка и рекомендации расширений
docs/                         Снимки работающего прототипа
```

Все модели создаются программно: скачивать сторонние 3D-ресурсы не нужно.
`packages.lock.json` фиксирует граф зависимостей. В CI запускаются Release-сборка
и физические тесты. Архив исходников не включает SDK, `bin/`, `obj/` и кэш NuGet.
